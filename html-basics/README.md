# Основы HTML

Самый небольшой пример в коллекции: один HTML-файл с базовой структурой документа и текстом в теле страницы.

## Запуск

Откройте `index.html` в браузере. Зависимостей, сборки и серверной части нет.

## Границы примера

Это отдельное упражнение по разметке, а не готовый сайт. Скриптов, оформления и пользовательских сценариев в исходнике нет. Видимый текст в публичной копии обезличен; функциональность не добавлялась. Разметка проверена статически, браузерная проверка не выполнялась.
