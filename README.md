# Веб-эксперименты

Четыре небольших авторских упражнения по HTML, CSS, JavaScript и HTTP. Коллекция сохраняет фактический объём исходников: от одной страницы до простого Express-маршрута.

## Проекты

| Проект | Что изучается | Технологии | Как посмотреть |
| --- | --- | --- | --- |
| [Генератор случайного числа](random-number-demo/README.md) | DOM, таймер, случайное число | HTML · CSS · JavaScript | Открыть `index.html` |
| [Основы HTML](html-basics/README.md) | Структура HTML-документа | HTML | Открыть `index.html` |
| [HTTP-запрос и JSON-ответ](http-data-demo/README.md) | `fetch`, JSON и Express | HTML · CSS · JavaScript · Node.js | Установить Express и запустить `server.js` |
| [Учебный эскиз страницы](coursework-markup/README.md) | Разметка будущего интерфейса | HTML | Только просмотр; JS и CSS отсутствуют |

## О публичной копии

Видимые личные и непубличные тексты заменены нейтральными. Несогласованные имена файлов приведены к ссылкам в HTML; в HTTP-примере статические файлы помещены в папку, которую уже использовал исходный сервер. Git-история и локальные служебные файлы в коллекцию не включены.

Три JavaScript-файла проверены на синтаксис, локальные ссылки в HTML и README проверены статически, секреты проверены Gitleaks. Две ссылки на отсутствующие ресурсы в учебном эскизе сохранены и явно описаны. Сборка, запуск Express и браузерные сценарии при переносе не выполнялись. Отсутствующий backend или продуктовые функции не добавлялись.

Спорные по авторству соседние папки в эту коллекцию не входят. Каждый пример описывает собственные зависимости и ограничения в README.
