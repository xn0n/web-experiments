# Учебный эскиз страницы

Сохранившийся HTML-фрагмент учебной работы: заголовок, кнопка вызова `fetchData()` и контейнер результата.

## Просмотр

Откройте `index.html` в браузере, чтобы посмотреть разметку. В исходной папке не было связанных `styles.css` и `script.js`; эти ссылки оставлены как свидетельство незавершённой структуры.

## Границы примера

Кнопка не работает без отсутствующего `script.js`, а оформление не загружается без `styles.css`. Серверной части среди исходных файлов нет. Назначение реального сервиса и завершённость курсовой по одному HTML-файлу не подтверждаются.

В публичной копии файл `html` получил имя `index.html`, а видимые тексты обезличены. Недостающие файлы и функции не создавались. Выполнена статическая проверка разметки с фиксацией двух отсутствующих ресурсов; браузерная проверка не выполнялась.
