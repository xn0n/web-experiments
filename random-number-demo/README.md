# Генератор случайного числа

Небольшой учебный пример взаимодействия HTML, CSS и JavaScript: кнопка меняет состояние страницы, а через пять секунд показывает случайное целое число от 1 до 1 000 000 000.

## Что находится в проекте

| Файл | Назначение |
| --- | --- |
| `index.html` | Страница, кнопка и место для результата |
| `styles.css` | Оформление страницы |
| `script.js` | Генерация числа и отложенное обновление текста |

## Запуск

Откройте `index.html` в браузере. Сервер и внешние API не требуются.

## Границы примера

Это демонстрация DOM и таймера. Генератор использует `Math.random()` и не подходит для паролей или криптографии. Название исходной папки `chatgpt.site` не означает наличие интеграции с ChatGPT: вызовов AI-сервисов в этих файлах нет.

В публичной копии UI-тексты заменены на нейтральные, а имена CSS и JS приведены к ссылкам из HTML. Логика диапазона и пятисекундной задержки сохранена. Выполнена проверка синтаксиса JavaScript; поведение в браузере при переносе не проверялось.
