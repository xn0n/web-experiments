# HTTP-запрос и JSON-ответ

Учебный пример связи браузера с небольшим Express-сервером. Кнопка выполняет `fetch('/api/data')`, сервер возвращает JSON с полем `message`, а страница показывает фиксированный текст об успешном получении данных. Содержимое ответа пока не выводится.

## Устройство

| Файл | Назначение |
| --- | --- |
| `server.js` | Express, статическая папка `public`, порт 3000 и GET `/api/data` |
| `public/index.html` | Страница с кнопкой и блоком статуса |
| `public/script.js` | HTTP-запрос, разбор JSON и обновление DOM |
| `public/styles.css` | Базовое оформление |

## Локальный запуск

Нужны Node.js и библиотека `express`. В исходной папке отсутствовали `package.json` и lock-файл, поэтому версия зависимости не закреплена. Для отдельного локального ознакомления выполните в этом каталоге:

```sh
npm install --no-save --package-lock=false express
node server.js
```

Затем откройте `http://localhost:3000`. Останавливается сервер сочетанием `Ctrl+C`.

## Границы примера

Сервер содержит только демонстрационный маршрут. Здесь нет базы данных, авторизации, AI-интеграции, сохранения результатов или производственной конфигурации. Ошибка запроса выводится в консоль, отдельное состояние ошибки в интерфейсе не реализовано.

В публичной копии HTML, CSS и JS помещены в уже ожидаемую сервером папку `public`, нормализованы имена файлов и обезличены тексты ответа/интерфейса. Маршрут и порт сохранены. Синтаксис двух JS-файлов проверен; установка Express, запуск сервера и сценарий в браузере при переносе не проверялись.
